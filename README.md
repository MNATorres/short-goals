# Short Goals

A personal short-term goals tracker written in Kotlin.

The idea: keep a lightweight list of small, concrete goals (daily or weekly),
mark progress on them, and review what got done — without the overhead of a
full task manager.

## Status

🚧 Early setup — project skeleton only.

## Requirements

- JDK 21+

## Getting started

```bash
./gradlew build   # compile and run tests
./gradlew run     # run the application
```

## Project layout

```
src/
├── main/kotlin/   # application code
└── test/kotlin/   # tests
```
